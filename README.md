# 🚖 Uber Booking Data - Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on an Uber booking dataset to understand booking patterns, cancellations, ride values, customer behavior, driver performance, and operational trends.

The analysis includes data cleaning, handling missing values, feature engineering, visualization, and extracting meaningful business insights using Python.

---

## 📂 Dataset
The dataset contains information related to Uber bookings, including:

- Booking ID
- Booking Status
- Customer ID
- Vehicle Type
- Pickup Location
- Drop Location
- Average VTAT
- Average CTAT
- Customer Rating
- Driver Ratings
- Ride Distance
- Booking Value
- Cancellation Reasons
- Incomplete Ride Reasons
- Date & Time

---

## 🎯 Objectives

- Understand booking trends.
- Analyze cancellation patterns.
- Study customer and driver ratings.
- Identify peak booking hours.
- Explore ride distance and booking values.
- Handle missing values and inconsistent data.
- Generate business insights through visualization.

---

## 🛠️ Technologies Used

- Python

## 📊 Exploratory Data Analysis

### Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Standardized categorical values.
- Converted data types.
- Treated invalid ratings.
- Cleaned date and time columns.

### Visualizations
- Vehicle Type Distribution
- Booking Value Distribution
- Ride Distance Distribution
- Driver Rating Analysis
- Cancellation Reasons
- Boxplots for Outlier Detection
- Vehicle type and rides cancelled by drivers
- Ride distance vs Booking value
- Avg VTAT VS Avg CTAT
- Payment method
- Hour
- Pickup location
- Drop Location

---

## 📈 Key Insights

- Completed rides make up the majority of bookings.
- Certain pickup locations receive significantly more bookings.
- Most ride distances fall within a moderate range.
- Booking values are positively correlated with ride distance.
- Customer and driver ratings are generally high with few invalid entries.
- Driver and customer cancellations reveal operational bottlenecks.
